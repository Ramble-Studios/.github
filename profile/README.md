## Que es RAMBLE?

RAMBLE es una network de Minecraft centrada en survival con elementos RPG: skills, clases, profesiones y un mundo de isla rodeado de oceano.

No somos un servidor RPG puro, sino un **survival con profundidad**.

## Stack tecnico

- **Lenguaje:** Java 21
- **API:** Paper / Purpur 1.21.x
- **Proxy:** Velocity
- **Build:** Gradle
- **Base de datos:** MySQL + Redis
